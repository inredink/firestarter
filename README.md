# FLCL – Fire Starter (Faithful Game Recreation & ESP32-S3 Handheld Port)

Based on the 2005 recreation by **Marcello Bastea-Forte** (`marcello3d/firestarter`), with original music, graphics, and sound effects by **Zack Fowler**, additional music by **Travis Skare**, and `partypack` utilities by **X-G**.

## Overview

This branch (`flcl-handheld-port`) preserves the original 2005 gameplay baseline in full while delivering both the **Desktop build** and the **Dedicated ESP32-S3 Portrait Handheld Firmware**:

1. **`FIRE STARTER` Title Screen ([`src/IntroSequence.h`](src/IntroSequence.h), [`src/IntroSequence.cpp`](src/IntroSequence.cpp))**:
   - Replaces the old character splash image (`data/title.png` is preserved untouched in `data/`) with a monochrome green `FIRE STARTER` title screen over a deterministic isometric city backdrop constructed from the original game's road and building tiles (`data/roads.png`, `data/building0.png`–`data/building3.png`, `data/construction0.png`, `data/rubble.png`).
   - Displays an unobtrusive `press start` instruction beneath the title and accepts `START` (`Enter`) or `A` (`A` key) to begin a new game.

2. **Six-Screen Introductory Narrative Sequence ([`src/IntroSequence.cpp`](src/IntroSequence.cpp))**:
   - Implements a deterministic state machine (`TITLE` -> `INTRO_FADE_IN` -> `INTRO_READING` -> `INTRO_FADE_OUT` -> `GAME_INITIALIZATION` -> `GAMEPLAY`) that presents all six narrative passages verbatim in order:
     1. `"No one knows how Endsville, the city of devils, was created, but as soon as it appeared, it started to grow, and slowly eat up the world."`
     2. `"You are an agent of Canti, the God of the Black Flame... and you must stop Endsville from destroying the world."`
     3. `"Your only weapon is flame:  matches, lighters, and fire-bombs. Get the weapons, outsmart the firefighters, hide from the police."` *(preserving the two spaces after `flame:`)*
     4. `"Torch the city, and purge its demons. But you must be careful; you cannot burn everything."`
     5. `"If the entire city burns down, there will be no place to live. Thus, the battle is endless: there is no final victory. The only thing you can do is burn... and burn... and burn..."`
     6. `"Your highest goal is to receive the personal blessing of Canti, the God of the Black Flame..."`
   - Smooth 800 ms monochrome green fade-in and fade-out transitions (`FADE_IN_TICKS = 80`, `FADE_OUT_TICKS = 80` at 100 Hz).
   - Automatic reading timers scaled to passage length (8.0s to 12.0s) and safe manual advancement via `START` (`Enter`) or `A`, ignoring inputs during active fade transitions.
   - Transitions directly from Screen 6 into `MainGame::setup()` with an 800 ms fade-in to gameplay.

3. **Configurable Portrait Display Resolution ([`src/DisplayConfig.h`](src/DisplayConfig.h), [`src/FireStarter.cpp`](src/FireStarter.cpp), [`src/MainGame.cpp`](src/MainGame.cpp))**:
   - Default target display resolution is `240 × 320` (`FIRESTARTER_DISPLAY_WIDTH`, `FIRESTARTER_DISPLAY_HEIGHT`), scaled by `FIRESTARTER_WINDOW_SCALE` (`1x` native on ESP32-S3 ST7789 TFT, `2x` -> `480 × 640` on desktop).
   - `MainGame` renders to its internal `200 × 300` logical canvas (`gameCanvas`) and scales cleanly to the target display resolution so gameplay mechanics, collision math, and HUD elements remain 100% unchanged and unclipped.

4. **Dedicated ESP32-S3 Handheld Firmware Port ([`platformio.ini`](platformio.ini), [`src/platform/`](src/platform/))**:
   - **Zero SD Card / Filesystem Dependency**: All 17 PNG bitmaps (pre-decoded to 16-bit `RGB565` in Flash `.rodata`, saving ~809 KB of SRAM), 2 `.nws` animated sprites, 2 bitmap fonts (`DATA_FONTS_alpha`, `DATA_FONTS_score`), 2 WAV sound effects (`fire.wav`, `siren.wav`), and the 16-bit tracker rendition of **"Stalker Goes to Babylon" by The Pillows** ([`data/stalker_babylon.xm`](data/stalker_babylon.xm)) are embedded directly in [`src/platform/EmbeddedAssetsData.h`](src/platform/EmbeddedAssetsData.h) (generated by [`tools/export_embedded_assets.cpp`](tools/export_embedded_assets.cpp)).
   - **Drop-In Embedded Allegro + DUMB Layer ([`src/platform/EmbeddedAllegro.cpp`](src/platform/EmbeddedAllegro.cpp))**: Implements 16-bit `RGB565` software blitting, sub-bitmaps, sprite horizontal flipping, bitmap font rendering, and an in-memory DUMB tracker + multi-voice WAV sound effect mixer (`esp32_render_audio_stream`).
   - **Hardware Drivers ([`src/platform/ESP32Main.cpp`](src/platform/ESP32Main.cpp), [`src/platform/ESP32PinConfig.h`](src/platform/ESP32PinConfig.h))**: Self-contained 40 MHz SPI `ST7789` `240 × 320` portrait display driver, Core 0 FreeRTOS `MAX98357A` I2S digital audio task (`22,050 Hz` 16-bit stereo/mono), and active-LOW GPIO tactile button polling.

## Controls & ESP32-S3 Pinout ([`src/platform/ESP32PinConfig.h`](src/platform/ESP32PinConfig.h))

### Handheld Controls

| Action | Desktop Key | Handheld Control | Default ESP32-S3 GPIO (Active-LOW to `GND`) |
| :--- | :--- | :--- | :--- |
| Move Up | `Up Arrow` | Left Pad `UP` | `GPIO 5` |
| Move Down | `Down Arrow` | Left Pad `DOWN` | `GPIO 6` |
| Move Left | `Left Arrow` | Left Pad `LEFT` | `GPIO 17` |
| Move Right | `Right Arrow` | Left Pad `RIGHT` | `GPIO 18` |
| Burn / Confirm | `A` | Right Pad `A` | `GPIO 13` |
| Secondary (`B`) | `Z` | Right Pad `B` *(optional)* | `GPIO 1` |
| Start / Advance Intro / Pause & Map | `Enter` | Top Right Angled Pill (`START`) | `GPIO 38` |
| Switch Music Track | `Right Shift` | Bottom Right Angled Pill (`SELECT`) | `GPIO 39` |
| Return to Title Screen | `F2` | Hold `START + SELECT` (1.5s) | `GPIO 38 + GPIO 39` |

### ST7789 `240 × 320` Portrait SPI Display Wiring

| ST7789 Pin | ESP32-S3 GPIO | Notes |
| :--- | :--- | :--- |
| `VCC` | `3V3` | 3.3V logic & power |
| `GND` | `GND` | Common ground |
| `DIN` (`MOSI`) | `GPIO 35` | `PIN_TFT_MOSI` |
| `CLK` (`SCLK`) | `GPIO 36` | `PIN_TFT_SCLK` |
| `CS` | `GPIO 9` | `PIN_TFT_CS` |
| `DC` | `GPIO 10` | `PIN_TFT_DC` |
| `RST` | `GPIO 11` | `PIN_TFT_RST` |
| `BL` | `GPIO 12` | `PIN_TFT_BL` (HIGH = Backlight ON) |

### MAX98357A I2S Class-D Amplifier Wiring

| MAX98357A Pin | ESP32-S3 Pin | Notes |
| :--- | :--- | :--- |
| `VIN` | `3V3` or `BAT` | 3.3V–5V supply |
| `GND` | `GND` | Common ground |
| `BCLK` | `GPIO 14` | `PIN_I2S_BCLK` |
| `LRC` (`WS`) | `GPIO 15` | `PIN_I2S_LRCLK` |
| `DIN` | `GPIO 16` | `PIN_I2S_DOUT` |

## Building & Flashing

### Option A: ESP32-S3 Handheld Firmware (PlatformIO)

1. Install [VS Code](https://code.visualstudio.com/) and the **PlatformIO IDE** extension.
2. Open this repository folder in VS Code.
3. Connect your **Adafruit Feather ESP32-S3** (`adafruit_feather_esp32s3`) or **Waveshare ESP32-S3-Pico** (`waveshare_esp32_s3_pico`) via USB-C and run:

```powershell
# For Adafruit Feather ESP32-S3 (default)
pio run -e adafruit_feather_esp32s3 -t upload

# For Waveshare ESP32-S3-Pico
pio run -e waveshare_esp32_s3_pico -t upload
```

### Option B: Desktop Build (Windows / MinGW)

```powershell
make clean
make all EXTRA_CFLAGS="-I../toolchain/mingw32/include" LIBDIR="-L../toolchain/mingw32/lib"
```
